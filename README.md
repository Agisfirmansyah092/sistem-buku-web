# Sistem Buku

Aplikasi Flutter untuk login, registrasi, katalog buku, cover, dan profil anggota.
Backend aktif: Supabase Auth + Postgres + Storage, untuk website dan APK Android.

- Setup dan pengujian: [supabase/README.md](supabase/README.md)
- SQL tabel dan izin akses: [supabase/setup.sql](supabase/setup.sql)
- Build website/APK: [HOSTING.md](HOSTING.md)

Folder backend menyimpan API PHP lama sebagai referensi. Flutter tidak lagi
memanggilnya. Data XAMPP tidak otomatis dipindahkan ke Supabase.
